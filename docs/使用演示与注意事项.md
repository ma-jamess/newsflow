# 使用演示与注意事项

适用版本：Codex 1.2.0。2026年10月22日已在 Microsoft Edge 实际演示单条分类、三算法对照、旧结果提醒、批量预览、批量分类、人工标注与实验算法切换。

## 启动和关闭

在 PowerShell 执行：

```powershell
cd C:\Users\30909\bishe\news-title-classifier-codex
python run.py
```

也可双击项目中的 `run.bat`。使用 Python 3.11–3.13；首次安装依赖需要联网，准备完成后分类在本机运行，不需要 AI API 密钥。页面地址为 `http://127.0.0.1:8510`。不要直接双击 `web/index.html`，页面需要 Python 服务。

使用源码包时，先完整解压，再在解压后的项目根目录启动。保留 `data`、`artifacts`、`newsroom`、`web` 等目录。日常使用不需要执行 `--retrain`；它重新运行训练实验。

正常启动时保留运行窗口；在该窗口按 Ctrl+C 关闭服务。仅关闭浏览器不会关闭 Python。若出现端口占用，执行 `python run.py --port 8511` 并使用启动窗口显示的地址。若服务器重新启动后页面提示刷新重试，刷新页面即可。服务只接受 `127.0.0.1` 标准地址。

## 三分钟演示顺序

1. 打开“标题分类”，保留推荐的线性 SVM 与阈值 0.65。点“科技示例”，再点“开始分类”。本次演示预测科技，概率 98.9%；右侧同时列出五类概率和“芯片”等文字特征。
2. 点“同一标题对照三种算法”。本示例三种判断一致：朴素贝叶斯 97.6%、逻辑回归 97.3%、SVM 98.9%，均预测科技。对照结果不投票替换推荐模型，也不生成三条历史。
3. 把标题改为“高校公布今年招生计划”。旧单条结果和算法对照会提醒重新运行。点“开始分类”，本次预测教育，概率 99.9%。点击“人工核对”，确认教育并填写备注，保存后到“历史与纠错”查看。
4. 打开“批量处理”，粘贴下列五条标题，再在最后保留一个空行。点“先预览输入”，应显示6条、1条无效；点“批量分类”，应得到5条完成、1条输入无效。可以搜索标题、按状态筛选，再点“导出全部结果”。导出包含本批全部行，不受页面筛选限制。
5. 打开“实验评估”，讲解准确率、宏 F1 和数据划分。切换“混淆矩阵模型”会同步更新矩阵、分类别表现和错误样本。顶部推荐算法仍是 SVM；“下载所选算法全部误分类”跟随当前矩阵模型。SVM 的完整错误文件为153条，逻辑回归165条，朴素贝叶斯242条，页面最多展示30条。

```text
足球队夺得联赛冠军
人工智能芯片发布
高校公布招生计划
银行股集体上涨
新电影举办首映礼
```

示例结果用于展示功能。五条示例全部正确不代表真实业务准确率为100%。本项目独立测试集4989条上，SVM准确率为96.93%。

## CSV 怎样准备

可直接使用 `examples/batch-demo.csv`，或点击页面“下载 CSV 示例”。CSV 必须有 `title` 或 `标题` 列；可选 `label` 或 `真实类别` 列，标签使用体育、科技、教育、财经、娱乐。

```csv
title,label
足球队夺得联赛冠军,体育
人工智能芯片发布,科技
高校公布招生计划,教育
银行股集体上涨,财经
新电影举办首映礼,娱乐
```

文件支持 UTF-8、GB18030，最大5 MB、5000条，每个标题最多200字。Excel 可另存为“CSV UTF-8”。标题含逗号时应按标准CSV规则引用，使用Excel保存通常会自动处理。

已选择文件时，系统优先处理文件。想改用粘贴输入，先点“清除文件”。预览只展示前10条并检查输入，不运行分类。修改输入、批量算法或核对阈值后，需要重新分类。

有有效真实标签时会显示本批准确率与宏 F1；仅对有有效标签和预测的行计算。空标题仍保留在输出中。批量结果不写入历史；切换到新输入或刷新页面前先导出。

本次CSV上传解析与导出内容已通过本机HTTP接口验证。浏览器自动选择文件未完成验收；请用“选择文件”手工选取。浏览器下载完成事件没有返回，但本次导出接口核对了6行、UTF-8 BOM和空标题状态。备用演示结果见 `examples/演示批量分类结果.csv`，仍需在实际答辩电脑上手工试一次文件选择与下载。

## 如何理解概率和人工核对

默认阈值0.65。最高概率低于阈值，或前两类概率差小于0.15，都会提示人工核对。调高阈值通常增加需核对条数；它不会修改模型权重或提升模型测试准确率。批量页面有自己的核对阈值，默认0.65，独立于单条分类；修改后重新批量分类。

高概率、三算法一致都不能保证正确。例如短标题“特斯拉发布新车”在已有历史中出现过算法分歧，朴素贝叶斯甚至以95.1%预测为体育。这说明短标题、新词和跨领域内容需要结合正文判断，不应只看分数。

文字特征说明原始模型得分受到哪些词语或片段影响，不是事实核查，也不是概率增加量。系统只支持五类；政治、军事、医学等五类外新闻可能仍被归到其中一类。

## 历史、纠错和答辩资料

每次单条分类保存到 `runtime/history.sqlite3`。人工标注仅留档，不自动训练，也不立即改变下一次预测。历史页面展示最近1000条，导出最近5000条，更早记录仍保存在数据库。需要迁移历史时，先停止服务再备份整个 `runtime` 目录；源码发行包不包含本机历史。

论文配图位于 `thesis/figures`，比较说明位于 `docs/版本对比.md`。论文DOCX是技术初稿，提交前核对学校模板、个人信息和引用。正式准确率来自固定历史语料，不代表所有最新新闻；不能把测试集错误用于调参后继续沿用原独立测试结论。

系统使用传统机器学习，不调用 DeepSeek 或 OpenAI API。DeepSeek 参考版保存在原目录，本次复核108个文件均未改变。

## 1.2新增操作

分类结果可复制，标题输入框Ctrl+Enter提交。批量完成后查看五类分布，可点击类别和组合状态筛选；“导出待核对”导出整批review、unknown、invalid行，全部导出仍包含全批。历史页选择待核对未标注与低概率优先，人工确认后记录会移出该队列。页面顶部有使用指南。
