# NewsFlow 1.4 使用与演示

NewsFlow 把“输入一个标题再分类”的毕设扩展成可以日常使用的新闻工具。
打开首页即可看近期新闻，同时保留完整实验页面，适合演示应用功能与解释算法。

## 五分钟开始使用

解压完整源码包，进入 `NewsFlow` 文件夹，双击 `run.bat` 或运行 `python run.py`。
默认 Edge 打开 `http://127.0.0.1:8510`。首次准备依赖需要联网；新闻订阅也需要联网。
已缓存的新闻与本地分类功能可继续使用。

1. 在侧栏选“科技”或其他类别；手机上使用新闻页的横向分类按钮。
2. 搜索关键词，再选来源。搜索匹配标题与摘要，分类、来源、收藏和待核对取交集。
3. 点击标题，查看摘要、来源发布时间、分类概率和文字特征；“阅读原文”打开发布方网站。
4. 点星标收藏。在“我的收藏”里查看；重开浏览器或程序后仍保留。
5. 模型判断有误时，在详情中选正确类别并保存。也可标记“待核对”。
6. 点“导出 CSV”导出当前筛选结果，最多 5000 条，包含来源、原文地址、发布时间与人工标注。

默认只有近 72 小时新闻；收藏视图可以查看更早的新闻。
没有发布时间的条目显示“时间未标注”，并按本机首次收录时间排序。
未收藏缓存保留七天，收藏不因自动清理而删除。

## 新闻更新到底有多快

服务启动后先获取一批新闻，然后每 120 秒检查 RSS/Atom。页面通常每 20 秒读取本机缓存；
第一次更新或手动更新时会短暂加快读取。手动检查更新的冷却时间为 30 秒。

这是周期检查，新闻源发布后才能读取。本工具不承诺秒级推送。
“最近检查”指本机检查订阅的时间；新闻卡片和“最新发布”指来源给出的发布时间。
成功返回 HTTP 200 的旧订阅会标记“近期未更新”，不会显示成刚发布的新闻。

默认来源为 IT之家、少数派、中新网体育、财经和教育订阅，已在 2026-10-31 实测。
默认内容偏科技，分类数量不平均；每条新闻由模型按标题归类，不直接采用来源频道作为答案。
娱乐内容可以来自这些来源的跨领域新闻，也可开启“中新网 · 即时”或添加自己的娱乐 RSS。
综合源包含五类以外的新闻，浏览时应人工核对。

## 管理新闻源

“管理新闻源”显示每个来源的最新发布时间、最近成功读取、健康状态和启用开关。
关闭来源停止后续读取，原有缓存、收藏与标注保留。
新增来源填写名字与完整公开 HTTPS RSS/Atom 地址；只支持 443 端口，拒绝本机、私网地址和带账户密码的 URL。
来源失败时保留旧缓存，其他来源继续更新；可稍后手动重试。

每次最多并行读取 3 个源，每个源超时 10 秒、最多 1 MiB、80 条。
只保留标题和文本摘要，不下载文章全文、图片或运行订阅中的 HTML。

## 答辩演示顺序

先展示当天新闻、分类筛选、搜索与收藏；再点开一条新闻说明“分类概率表示模型倾向”。
在详情中修改类别，刷新后确认人工标注保留，说明应用功能和机器学习实验的边界。

点击“带到快速分类”只会填入标题。选择本地 SVM，手动分类、查看实际特征与三种算法对照；
然后用 `examples/batch-demo.csv` 演示批量预览、类别分布与待核对导出。
最后进入实验评估，说明训练、选参、校准、测试四部分数据，比较 NB/LR/SVM 与混淆矩阵。

旧测试集的 96.9333% 是推荐 SVM 在固定历史测试集上的准确率。
它不能作为当前 RSS 新闻的准确率，来源更新成功也不能证明分类准确。
人工标注只修改本机应用记录，不自动用于再训练，不更改测试报告。

DeepSeek 仅用于用户手动提交的单条标题；自动新闻与批量分类使用本地模型。
没有配置密钥也能完成全部日常新闻功能和本地实验。

## 数据、共享与开源

新闻与来源设置在 `runtime/news.sqlite3`，快速分类历史在 `runtime/history.sqlite3`。
这些文件以及 `runtime/deepseek.env` 不在源码包中。其他人解压后创建自己的本机数据。
环境变量 `DEEPSEEK_API_KEY` 优先于本机密钥文件，使用第三方接口时应由使用者配置自己的密钥。

应用代码使用 MIT；上游数据和图标许可证随包保留，新闻文字权利属于原发布方。
源码包包含程序、模型、实验数据、报告、测试与使用说明，可以分发给他人安装。
程序默认监听 `127.0.0.1`，这次版本面向每个人各自在本机使用。

参考项目：[NewsNow](https://github.com/newsnext/newsnow)、
[Horizon](https://github.com/Thysrael/Horizon)、
[AI News Radar](https://github.com/LearnPrompt/ai-news-radar)。
本次采用 RSS 缓存、列表与详情等组织思路，保持原有 Python 和原生网页结构；没有复制上游代码。
