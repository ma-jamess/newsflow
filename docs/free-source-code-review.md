# 免费来源扩充复核

2026-11-02，对整个来源扩充改动进行了独立只读复核。128 源容量、稳定来源 ID、个人偏好保留、每源内容预留及工作流权限检查通过。复核提出两项重要问题，已在同一次修复中解决：

1. 新浪财经的 `rollnews.xml` 返回 2008 年存档，缺少日期使旧文章按首次收录时间进入近期列表。已排除这个订阅；无日期但 URL 含明确旧日期目录的文章不进入新快照，也不能从旧快照恢复。只用日期目录排除存档，保留发布时间为空。
2. 含过旧日期文章和无日期文章的订阅被误标为 `current`。已分开统计真实近期的已标日期条目与无日期条目；只有前者能标记当前。全无日期来源仍准确标为 `unknown_time`。

五个新回归用例均在修复前失败、修复后通过；完整 Python 测试 107 项、Node 测试 41 项通过。重建的本机公开快照有 43 来源、920 条文章，未包含 2008-06-12 存档。Edge 桌面和手机来源筛选、来源开关、布局与 JS 错误检查通过。

没有严重问题、待处理的小问题或复核未判断的行为。完整过程见 [执行记录](free-source-progress.md)，最终来源选择见 [选择记录](source-selection-2026-11-02.json)。上线后还将记录实际部署及旧收藏、纠错和来源偏好的连续性验证。
