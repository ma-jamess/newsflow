# 新闻阅读界面调整

2026-11-19 根据使用者选择，将 NewsFlow 的首页调整为简洁新闻阅读器。保留现有 Python、原生网页与 ECS 快照架构。

列表优先显示标题、类别、来源和发布时间。正常模型结果不再在每条标题旁重复显示百分比；概率分布和特征线索仍可在详情查看。待核对与人工类别标记保留。没有订阅摘要时，列表不填充重复的占位说明，详情仍提供原文入口。

页面标题改为“最新新闻”“标题分类”“批量分类”“分类实验”“历史与纠错”“设计与原理”。减少装饰性英文标签和宣传句，调整字体大小、文字对比、间距及移动端按钮尺寸。来源、刷新、收藏和人工标注的说明按实际行为表达。

2026-11-20 补充：长订阅摘要折叠显示，允许展开全部内容，原始摘要仍用于搜索与保存。来源的明显未来时间不作为“最新发布”显示。实验页面增加三个模型的独立验证报告下载，另提供只验证已有模型的脚本。

界面取舍是让读者先判断要读哪条新闻，需要检查分类时再展开模型信息。这是设计目的，没有用户实验测量阅读效率或风格偏好。

本次调整不改变 TF-IDF、分类器、训练数据、概率校准、核对阈值或模型文件。历史实验结果仍为 SVM 校准后 4,836/4,989，约 96.93%。人工标注不会自动训练模型。

写作与实现使用 AI 辅助，不将界面风格作为作者身份或独立完成的证明。学习问答依据实际功能更新，个人贡献按真实情况描述。
