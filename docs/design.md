# 中文新闻标题分类系统 · Codex 独立版本

作者：季金航。题目沿用《基于机器学习的中文新闻标题分类系统设计与实现》。

用户要求：研究已有成品，独立实现完整毕业设计应用；不改动已有版本；提供所有源码，使用 `python run.py` 启动。用户将具体实现选择交给本次开发，因此直接执行，不再追加设计批准流程。

## 实现选择

- Python 3.11–3.13；本地 HTTP 服务使用标准库，前端使用原生 HTML/CSS/JavaScript，默认 Edge 打开。无需账号、GPU、外部 AI API。
- 五类保持体育、科技、教育、财经、娱乐。单条预测、批量 CSV、实验评估、人工纠错、方法说明五个页面。
- 使用现有公开 THUCNews 数据的一份副本，保留上游许可证、原始清单和哈希；不复制应用代码或模型。清洗规则与参考版本一致，支持同测试集比较。
- 三种模型：词 TF-IDF + 朴素贝叶斯；词与字符 TF-IDF 联合 + 逻辑回归；同联合特征 + LinearSVC。全部在训练集拟合特征；dev 按种子 42 分为选参集和校准集，先锁定选参及推荐算法，再校准；最后一次评估 test。
- 展示准确率、宏 F1、每类指标、混淆矩阵、误分类、Brier 分数、ECE、耗时和模型大小。阈值默认 0.65，分数差小于 0.15 也提醒核对；不是五类外识别器。
- 解释显示当前输入的线性特征贡献，含字符片段和词，说明其作用于原始判别得分而非因果关系或概率贡献。
- 历史和人工纠错写入本项目 SQLite；纠错只记录，不自动改模型、不污染测试集。用户可导出并用于后续独立标注实验。
- CSV 5 MB / 5000 行，标题 200 字；UTF-8/GB18030；空行和错误逐行呈现；可选 label/真实类别统计本批指标。导出防电子表格公式注入。
- 服务仅绑定 127.0.0.1；固定静态文件白名单、Host 校验、同源 POST 和随机请求令牌；模型从项目自己的已校验文件读取，不接受上传模型。
- 源码、数据、模型、复现实验脚本、测试、说明书、技术报告、答辩讲稿、版本对比与源码 ZIP 一并交付。

## 验收

1. 原版目录内容 SHA-256 前后相同。
2. 新版一条命令启动，五个页面能操作，单条与批量同输入输出一致，历史纠错持久化。
3. 独立训练产生实测报告；无跨数据集标题重复；测试集不参与调参或校准；对比明确注明不同训练策略。
4. 异常输入、模型篡改、上传错误、安全导出、API 和数据库行为通过测试；Edge 实际检查页面。
5. 换工作目录仍能启动；源代码包无需原版路径即可运行。
