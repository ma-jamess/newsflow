# 1.2 功能与界面设计

用户希望参考GitHub项目，让毕设功能合理、外观雅观；已回复“你决定，用你的审美来修改”。设计与执行细节由本次实现确定，保留Python本地运行和原版只读约束。

视觉：深青导航、浅灰背景、白色内容卡片，统一Lucide线条图标。增加中文字号和对比度，减少装饰标记，输入和结果保持清晰主次；兼容桌面与390px宽度、键盘焦点和减少动画设置。参考Tabler的信息分层，不引入Bootstrap或React。

功能：批量页面有独立0.20–0.95阈值，默认0.65；分类后显示五类分布，分母为有预测的标题，包含需要核对但有预测的行。按类别和状态筛选可组合，支持仅导出待核对行（review、unknown、invalid）；全部导出仍保留全部行。空输入、无预测和全无效批次不得产生NaN或虚构类别。

历史增加“待核对未标注”筛选及“低概率优先”排序，已标注记录从待核对队列移出；低概率不等于一定错误。借鉴Label Studio与modAL人工核对思想，不安装它们，不新增自动再训练。单条结果可复制，输入框Ctrl+Enter提交，保留三算法对照和旧结果提醒。

原生HTML/CSS/JS实现，无在线CDN、外部字体或新运行依赖。仅选取固定Lucide提交的少量SVG，保留原始许可证与出处。模型、特征、实验划分和测试成绩不变。既有Python、前端回归测试保留，新增测试验证分布、筛选、队列、阈值隔离。Edge实际操作并截图，生成1.2源码包。
