# NewsFlow 新闻分类小工具设计

用户要求：把现有新闻分类毕设重新设计成方便、实用的小工具，提供实时更新的新闻数据，并能让其他人安装使用。延续当前 1.3 的 Python、本地分类模型、DeepSeek 单条复核、批量分类与实验报告。

## 产品与界面

首页是新闻阅读与分类：打开后加载真实订阅源，后台每 120 秒检查更新。顶部搜索、立即刷新、新闻源管理；侧栏提供全部、体育、科技、教育、财经、娱乐、待核对及收藏。新闻列表显示原标题、来源、发布时间、分类和需要核对的状态；点击后在右侧查看订阅摘要、分类概率、原文链接，收藏或人工改类别。手机布局改为单列与可关闭详情。

品牌暂定 NewsFlow / 新闻分类小工具，白色与暖灰底、深青绿强调色、清楚的中文排版。借鉴 ThinkFlow 的导航、列表与详情组织方式。首页呈现实用新闻；手动分类、CSV 批量处理、历史、实验评估和原理分别保留独立入口。

## 更新和数据

- 默认接入已于 2026-10-31 实测的 IT之家、少数派、中新网体育、财经、教育 RSS，均有近期内容。中新网即时源作为可选择的额外来源。旧人民网源的返回内容停在 2016/2025 年，排除默认清单。
- 自动更新每 120 秒；页面每 20 秒读取本机缓存。立即刷新异步触发一次更新，已有更新运行时复用，连续手动请求至少间隔 30 秒。
- 保留新闻原始发布时间与本机抓取时间，分别标记；缺失发布时间显示“时间未标注”。显示每个来源最近成功抓取、最新新闻时间、错误或无新内容状态。HTTP 200 不直接当作新闻新鲜。
- 每个源最多读取 80 条，正文下载上限 1 MiB、单次网络超时 10 秒，最多并行 3 个源。RSS 与 Atom 支持，拒绝 DTD/实体声明；只存文本摘要，不抓取全文、图片或执行 HTML。
- 按规范化文章链接去重；刷新不重复插入。保留最近七天的未收藏缓存，收藏长期保存。首页默认近 72 小时；发布时间不明确的条目显式标记。新闻源返回旧数据时不当作刚发布的新闻展示。
- 来源失败时保留可用缓存；部分失败不会阻止其他源；全部失败时准确提示失败与缓存状态。
- 新闻缓存、来源设置、收藏、人工类别保存在 runtime/news.sqlite3，与既有历史分开，不进入源码包。新闻内容权利仍属于原发布方，只展示订阅标题、摘要和原文链接；本工具代码采用 MIT，第三方数据和图标许可证原样保留。

## 分类与编辑

- 自动新闻只调用现有推荐本地算法及阈值 0.65，不自动调用付费接口。五个训练类别沿用体育、科技、教育、财经、娱乐。
- 无预测或低置信结果进入待核对；低置信但有预测的条目仍展示预测类别，同时标记待核对。高概率不宣称保证正确，不宣称识别五类外输入或新闻真伪。
- 人工改类只修改新闻记录，刷新保持人工类别和收藏，不修改训练数据、模型、测试集或报告。可手动设置待核对。
- 详情可以把标题带到既有单条分类页，用户手动选择 DeepSeek 查看理由；不因为获取新闻而发出付费请求。
- 搜索、类别、来源、收藏与待核对筛选取交集。导出当前筛选结果 CSV，最多 5000 条，使用既有安全 CSV 导出。

## 工程合同

继续 Python 3.11–3.13、标准库 HTTP 服务、原生 HTML/CSS/JS 和现有 scikit-learn。新增功能不引入前端构建工具或付费新闻 API。

newsroom/feeds.py：内置来源清单、HTTPS 订阅地址验证、网络读取和 RSS/Atom 到统一条目的解析。自定义源必须是公网 HTTPS 地址、443 端口，无用户凭证；解析 DNS 和每次重定向时拒绝内网、回环、链路本地和保留地址。

newsroom/news_store.py：独立 SQLite 新闻存储、来源启停与添加、去重、收藏、人工类别、过滤查询、保留期和来源健康元数据。

newsroom/live_news.py：分类、更新协调、后台线程、详情与健康状态；所有网络操作通过可注入的读取边界，测试不访问真实网站。线程由实际应用启动，并在退出时停止。

newsroom/server.py 新增 GET /api/news、/api/news/sources、/api/news/detail；POST /api/news/refresh、/api/news/save、/api/news/feedback、/api/news/sources、/api/news/export。沿用本机 Host、Origin 与 X-Request-Token 防护，输入校验和参数化 SQL。GET 不触发付费或写入收藏。

web/live-news-ui.js 提供日期、状态和安全文本展示辅助；web/live-news.js 负责新闻页面、请求状态、筛选、收藏、详情、来源弹窗。旧页面保留现有 DOM 接口；app.js 导航增加 news，并暴露初始化完成 Promise。

run.py 创建并关闭实时新闻服务，默认端口仍 8510。源码包名称更新为 NewsFlow_1.4_完整源码.zip，包含 README、LICENSE、全部源码、可复现实验和旧功能；排除缓存、密钥、个人记录和临时文件。

## 已确定的取舍

“实时”落实为周期检查而非来源推送：本工具每两分钟检查，新闻出现时间受源发布节奏影响。默认模式供个人在本机使用，其他人通过源码包安装各自实例。账号、多人共享服务、全文生成和专题创作不在这次小工具范围。
