## 交付

新增公网交付模式，继续复用现有新闻布局、NewsController、RSS 读取、缓存规则和本地推荐分类模型。公网模式提供五类新闻、搜索、来源显示选择、详情与原文、模型概率与特征解释、个人收藏、人工纠错和安全 CSV 导出，并可查看固定历史实验报告。完整 Python 毕设程序继续提供下载，训练和任意标题/CSV 分类在下载版运行。公网新闻页不暴露本机服务、付费 API、个人历史或共享写入接口。

## 实现决定

GitHub Actions 每 5 分钟尝试抓取公开 RSS、运行已有本地 SVM 分类、生成静态 JSON 并部署 Pages。调度可能延迟，不承诺秒级推送或 2 分钟采集。浏览器每 20 秒检查已发布数据；手动刷新仅检查已发布数据，不让匿名用户触发工作流。来源健康、来源发布时间、采集完成时间与浏览器检查时间分别保留。

脚本使用临时 SQLite，绝不访问 runtime/deepseek.env 或个人数据库，不导入或调用付费提供方。延续 HTTPS 公网地址校验、3 源并发、10 秒超时、1 MiB 上限、72 小时默认新闻及七天未收藏保留。尝试读取上次成功发布的公网 JSON；缺失时使用干净的公开种子快照。部分来源失败仍保留旧新闻。全失败但有缓存时发布准确的缓存/错误状态；没有任何有效数据则构建失败，保留上一部署。

个人收藏保存文章快照，人工类别和来源偏好分别存在当前浏览器的 localStorage。缓存更新不能覆盖这些个人信息；旧收藏仍可查看，两个浏览器不共享编辑。浏览器拒绝存储或空间不足时保存失败必须明确提示，不能假装保存成功。断网有有效快照时显示缓存与错误提示，首次无数据则可重试。

新增 PublicBackend 适配原 NewsController 的 GET 列表/详情/来源、POST 收藏/纠错/来源选择/检查、CSV 导出接口；这些是浏览器内方法，不向任何写入服务发送请求。只请求同源 data/news.json 和 data/report.json。验证 JSON 结构、类别、URL、有限概率和时间，旧网络响应不能覆盖新快照。沿用安全文本输出和原文 noopener；CSV 防公式注入。

公开 HTML 复用原新闻页 DOM 合同，另有简洁公网 shell 与实验报告页。现有 live-news.js 增加由 bootstrap.public_site 控制的文案和下载入口分支，下载版本原行为保留。网页 CSP 仅允许同源脚本/连接，允许原概率条需要的内联样式，不含外部字体和付费服务。

部署动作固定到已通过 GitHub API 验证的 commit SHA；构建 job 仅 contents:read，部署 job 仅 pages:write/id-token:write。任务不把 GitHub token 写进产物或源码。构建输出 site/ 只含允许的网页资源、公开数据、公开实验报告和许可证。
