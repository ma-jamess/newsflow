DATA

先划清数据边界

公开 THUCNews 新闻标题子集。先清洗、排除标签冲突，跨训练 / 验证 / 测试集去重。特征词表和 IDF 只由训练集学习。

验证集按类别分层切分：一半选择参数与推荐算法，另一半校准概率。测试集在这些决定完成后才用于最终评估。

固定数据提交、随机种子42、文件哈希和完整训练源码随项目提供。

EXPLANATION

解释从真实特征计算

显示本标题 TF-IDF 特征值乘以预测类别与第二候选类别的线性权重差。片段或词语越有区分力，贡献越大。

这些数值说明原始分类得分受到哪些特征影响；它们不是因果解释，也不是概率增量。

训练脚本同时保留校准前后指标，用于评估校准的实际影响。

IMPLEMENTATION

完整本地实现

Python 标准库 HTTP 服务，原生 HTML / CSS / JavaScript 页面，scikit-learn 模型，SQLite 历史数据库。

python run.py
python run.py --retrain
python -m pytest -q

默认 Edge，服务只监听127.0.0.1。源码和训练资源都在独立项目目录。

LIMITATIONS

认识结果的边界

模型只学过五类新闻；医学、政治、军事等内容仍可能被分到最接近的类别。高概率也不能保证正确，校准不是五类外检测。

数据年代较早，当前新词与热点存在分布差异。正式应用前应增加新数据和独立评估。

人工纠错仅供标注留档；未来再训练应另外划分数据，不能把测试错误直接用于训练后继续报告原测试指标。

选择你的新闻来源

添加一个订阅

从这里开始

  1. 浏览新闻

    按分类和来源筛选，搜索标题与摘要。每 2 分钟检查订阅，也可以手动检查；发布时间来自原始新闻源。

  2. 收藏与核对

    点击标题查看详情、打开原文或收藏。可人工修改类别；收藏与标注保存在本机，刷新后保留。

  3. 分类与实验

    快速分类、CSV 批量处理、历史与实验评估保留在工作台。人工标注只留档，独立测试指标保持独立。

新闻自动分类使用本地模型。快速分类支持 Ctrl+Enter；选择 DeepSeek 后，手动提交的标题发送至官方 API 并按量计费。五类之外的新闻需人工核对。

人工核对

本次标注只保存在本机，不会自动更改模型。
